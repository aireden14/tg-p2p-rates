# tg-p2p-rates - @Checkp2pbot

Бот для быстрой оценки P2P-курса USDT ⇄ рубли. Пишешь сумму - сразу получаешь два варианта:
эта сумма в рублях → USDT и такая же сумма в USDT → рубли. План и решения - `PLAN.md`.

## Как считает
Курс = **Google (1 USD → RUB) + постоянная надбавка в рублях**. Живые объявления бот не смотрит: надбавку один раз
сняли с P2P Bybit (03.11.2026: «разумный выбор» - 3-е надёжное объявление - около +2,5 ₽ к Google) и считают постоянной.
В каждом сообщении формула показана (`Google 81,52 ₽ +2,50 ₽`), это оценка, а не живая цена.

- Надбавка по умолчанию +2,50 ₽ для покупки и продажи. Менять: переменные `P2P_BUY_MARKUP`, `P2P_SELL_MARKUP`
  (в Render: Environment) или `DEFAULT_MARKUP_RUB` в `p2p_rates/rates.py`.
- Проверить, не уехала ли надбавка: `python3 scripts/calibrate.py` на Маке (сравнивает Google с надёжными продавцами Bybit).
- Google берётся со страницы Google Finance (USD/RUB), кэш 5 минут; если Google недоступен, показывается последнее
  значение (не старше часа), иначе вежливое сообщение.

## Как пользоваться
- `/start` - панель: кнопки сумм (10 тыс … 1 млн) и «Обновить».
- Число в чате (`50000`, `50к`, `1,5 млн`) - пересчитать на свою сумму (от 1 до 1 млрд). `/rate 120000` - то же командой.

## Хостинг
Работает на бесплатном Render (Frankfurt, воркспейс «Indonesia's workspace», сервис `tg-p2p-rates`), код берёт из этого
репозитория. Бесплатный сервис засыпает через 15 минут без запросов, поэтому бот сам пингует свой `/health` раз в 10 минут.
Telegram опрашивается длинным опросом, так что входящий адрес нужен только для этого пинга.
Токен - переменная `TELEGRAM_BOT_TOKEN`. Одновременно запускать вторую копию бота с тем же токеном нельзя (Telegram даёт 409).

Раньше бот брал цены живых объявлений Bybit, но Bybit закрывает серверы хостингов (`403 Access Denied` из Frankfurt и
Singapore), поэтому на хостинге такой режим не работал; код Bybit (`p2p_rates/bybit.py`) оставлен для `scripts/calibrate.py`.

## Запуск и тесты
```bash
cd ~/services/tg-p2p-rates
python3 -m unittest discover -s tests          # тесты
TELEGRAM_BOT_TOKEN=... python3 -m p2p_rates    # бот в консоли (или токен в .env рядом)
SELFCHECK_ONLY=1 python3 -m p2p_rates          # только проверить, что Google отдаётся с этого места
```
Только стандартная библиотека Python. `install-autostart.sh` - автозапуск на Маке через launchd (сейчас не нужен: бот на Render).
Если вынуть SSD: бот на Render, Мак ему не нужен.
