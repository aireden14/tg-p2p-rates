# tg-p2p-rates - @Checkp2pbot

Бот для быстрой проверки P2P-курса USDT ⇄ рубли. Исходим из рублей: пишешь сумму, получаешь лучшие
объявления на покупку и на продажу USDT. Источник - P2P Bybit (Binance, OKX, Bitget, HTX рубли в P2P не отдают,
проверено 03.11.2026). План и решения - `PLAN.md`.

## Как пользоваться
- `/start` - панель: кнопки сумм (10 / 50 / 100 / 500 тыс), «Купить / Продать / Оба», «Только банк», «Обновить».
- Число в чате (`75000`, `50к`, `1,5 млн`) - пересчитать на свою сумму. От 500 ₽ до 3 500 000 ₽.
- `/rate 120000` - то же командой.
- «Надёжные» объявления: онлайн, выполнение ≥ 95 %, ≥ 30 сделок за 30 дней, без ограничения по гражданству,
  хватает объёма. Ориентир - медиана лучших 10.

## Запуск
Токен: `TELEGRAM_BOT_TOKEN` в окружении или строка `TELEGRAM_BOT_TOKEN=...` в файле `.env` рядом (права 600).
Без токена программа не падает: пишет строку в лог и раз в 30 с смотрит, не появился ли `.env`.

```bash
cd ~/services/tg-p2p-rates
python3 -m unittest discover -s tests     # тесты
python3 -m p2p_rates                      # бот в консоли
./install-autostart.sh                    # launchd: com.den.tg-p2p-rates
```

Только стандартная библиотека Python, зависимостей нет. Логи - `bot.log`, `bot.err.log`; настройки чатов - `state.json`.
Остановить: `launchctl bootout gui/$(id -u)/com.den.tg-p2p-rates`.

## Как устроено
- `p2p_rates/bybit.py` - запрос, разбор, фильтр надёжных, выбор лучших (`side=1` купить USDT, `side=0` продать).
- `p2p_rates/format.py` - сообщения (HTML), разбор суммы.
- `p2p_rates/bot.py` - клавиатура, настройки чата, кэш курса на 20 с, Telegram API.
- `tests/fixtures/` - сохранённые ответы Bybit (по ним идут тесты, живая сеть в тестах не нужна).

Если вынуть SSD: бот живёт на встроенном диске, не зависит от SSD и ничего не замечает.
